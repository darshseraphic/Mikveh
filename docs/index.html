07 / Privacy & security

Only the access
the feature needs.

Mikveh uses Chrome's storage permission to remember your theme preference and a host permission for HTTPS requests to bible-api.com, which provides the verse data.

The extension does not request permission to read your open tabs, page contents, browsing history, bookmarks, or downloads. It does not require an account.

Verse lookups and random-verse requests are sent to the Bible API. The API receives the requested reference (for searches) and normal request metadata such as IP address. Mikveh does not control the API provider's logging or retention practices.

iThe popup needs an internet connection to retrieve verse text. Theme choice is stored locally using Chrome extension storage. The current version does not include a verse-history or favourites feature.

10 / Frequently asked

A few things
worth knowing.

What does Mikveh do?

Mikveh is a Chrome extension that displays a random Bible verse when the popup opens and lets you search for a specific passage using a book, chapter, and verse reference.

Which Bible translation does it use?

The current extension uses the World English Bible (WEB) through bible-api.com. A translation selector is not currently included.

Does Mikveh work offline?

No. The extension needs an internet connection to request random verses and search results from the Bible API. The theme preference remains stored in Chrome, but verse text is not available offline through the current implementation.

What reference format should I enter?

Use the format Book Chapter:Verse, such as Luke 1:37. The extension also accepts the slash form, such as luke/1:37, for compatibility with the original command reference.

Does Mikveh save my searches or favourite verses?

The current version stores your theme preference only. It does not include verse history, favourites, user accounts, or cloud synchronisation.

Can I modify or redistribute the source?

Not under the current license by default. Mikveh uses a proprietary source-available license with limited personal-use permissions and restrictions on modification, derivative works, redistribution, and commercial use. Read LICENSE.txt and contact the copyright holder for permission.

Why is there no Chrome Web Store button?

Mikveh is not currently published in the Chrome Web Store. Installation instructions use Git clone and Chrome's Load unpacked workflow only.
