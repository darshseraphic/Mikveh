# Design credits

Mikveh's popup visual language follows the monochrome design guidance supplied for this project: calm ink-and-paper surfaces, task-first hierarchy, readable native typography, deliberate spacing, soft geometry, and consistent light/dark themes.

The project website's responsive project-page composition was informed by the website reference bundle supplied for this task. The website itself is independently written for Mikveh and uses the Mikveh cross artwork. It does not include the reference bundle's product assets, source files, external scripts, or font files.

The supplied reference bundle includes a `DESIGN_CREDITS.md` that attributes its own visual direction to **Unslop** by **Damir Sokolovsky**, under **Creative Commons Attribution 4.0 International (CC BY 4.0)**:

- Author: https://x.com/heydamir
- Project: https://heydamir.design/unslop
- License: https://creativecommons.org/licenses/by/4.0/

This note records the attribution stated in the reference material; Mikveh does not bundle the Unslop project or its assets.

## Website asset copies

The website uses the copies in `docs/icons/` because GitHub Pages configured to publish the `/docs` folder cannot serve files stored outside that folder. The canonical extension icon artwork remains in the repository-level `icons/` directory; keep the website copies in sync when the artwork changes.
